# Stage 17 — Genie access re-implemented on Genie One MCP (single auto-routed surface, no dropdown) — REAL run
# App lead-opt-review (https://lead-opt-review-7405610110498224.4.azure.databricksapps.com). Generated: 2026-09-16 (UTC).

## What changed (supersedes stage 14's per-space + dropdown approach)
- The app now asks GENIE ONE MCP: the single workspace-wide managed MCP server
  {host}/api/2.0/mcp/genie (server 'genie_chat'), NOT the per-space endpoint.
- No Genie space id, no room dropdown: Genie One routes each question to the right
  data itself via the workspace Genie Ontology.
- Client: genie/genie_mcp.py :: GenieOneMCP (genie_ask -> genie_poll_response).
- Genie One is async (~30-90s), so the app uses a start/poll pattern:
    POST /api/ask         -> {conversation_id, response_id, status:in_progress} (returns fast)
    GET  /api/ask/poll    -> {status, text(markdown), deep_link} ; the browser polls.
  (A single blocking request would hit the Databricks Apps proxy timeout — verified:
   the first synchronous attempt returned an empty body.)
- The app calls Genie One as its own service principal (client_credentials OAuth).

## Genie One MCP tools (live tools/list)
  genie_ask                 (req: question)
  genie_poll_response       (req: conversation_id, response_id)
  genie_get_query_result    (req: conversation_id, response_id, item_id)
  genie_cancel_response     (req: conversation_id)

## Takeaway (recorded honestly)
- Delivered the requested single auto-routed ask box (no dropdown). Preclinical NL and
  governance both verified live as the SP.
- Genie One's routing is non-deterministic / phrasing-sensitive: it will not reliably hit
  a narrow scoped space from loose phrasing in a shared workspace. Clinical correlation
  also remains available deterministically through the app's structured convergence panel
  and drill-in (which read the scoped clinical_correlation_summary view directly, governed
  by UC, not via Genie). For a guaranteed-scoped NL room, the per-space or Genie Agent MCP
  server is the right tool; Genie One is the right tool for one workspace-wide surface.
